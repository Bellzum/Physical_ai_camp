# Physical AI Camp

This repository contains the Physical AI Camp project workspace.

The Agora voice agent work is being developed on the `improve-agora-audio-clean` branch. See that branch for the full setup guide covering:

- Agora Conversational AI voice agent
- Python FastAPI backend
- Next.js web frontend
- IoT device protocol support
- ngrok testing instructions

To view that work locally:

```bash
git switch improve-agora-audio-clean
```

Or compare branches:

```bash
git diff main..improve-agora-audio-clean
```
